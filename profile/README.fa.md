### آوانوبت — رزرو نوبت آنلاین دکتر 👋

> 🩺 **دسترسی به پزشک خوب، حقِ همهٔ ماست.**

آوانوبت مسیر دریافت خدمات سلامت را ساده می‌کند: پزشک را پیدا کنید، زمان را انتخاب کنید و نوبت بگیرید — در چند کلیک، هر زمان و هر جا.
پلتفرم سلامت دیجیتالی که توسط شرکت **[ویرا وب آریا](https://onwebs.ir)** توسعه داده شده است.

## 🔎 برای بیماران

| | |
|---|---|
| **جست‌وجوی هوشمند** | فیلتر بر اساس شهر، تخصص و زمان نوبت (صبح / ظهر / عصر)، یا مرتب‌سازی بر اساس اولین نوبت آزاد. |
| **پروفایل کامل پزشک** | سوابق و کد نظام پزشکی، آدرس مطب به‌همراه مسیریابی، خدمات و نظرات بیماران. |
| **رزرو در چند کلیک** | زمان را انتخاب و تأیید کنید — بدون تماس تلفنی و بدون انتظار. |
| **پیگیری نوبت** | وضعیت نوبت خود را هر زمان که خواستید ببینید و دنبال کنید. |
| **مطالب سلامت** | راهنماها و مقالاتی که با پزشکان متخصص تهیه شده — از آماده‌سازی و عوارض پرتودرمانی تا تغذیه در دوران درمان. |

**تخصص‌های فعال روی پلتفرم:** پرتودرمانی (رادیوتراپی) · دندانپزشکی · پزشک عمومی · جراحی استخوان و مفاصل · گفتاردرمانی

## 🎯 چشم‌انداز، مأموریت و ارزش‌ها
